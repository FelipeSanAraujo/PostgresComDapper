# Api de consulta e cadastro de itens
Esta api de cadastro e consulta de itens é um exemplo didático de utilização do DAPPER juntamente de um banco de dados POSTGRESQL

Endpoints:
> api/items

> api/items/{id}


### Verbos:
* GET - Retorna uma lista de itens préviamente inseridos no banco;
* GET (ID) - Retorna um item do banco que tenha o mesmo id passado na requisição;
* POST - Insere um item no banco;
* PUT - Atualiza um item;
* DELETE - deleta um item a partir do id passado na requisição.
